# Should I Change Jobs Right Now?

A simple, transparent decision helper to bring clarity to one of the most stressful life decisions.

## What this does
- Asks a small number of practical questions
- Uses clear, deterministic logic (no black box AI)
- Gives one of three recommendations:
  - Stay
  - Prepare to leave
  - Leave now

## Why this exists
People don’t lack information — they lack clarity.
This tool helps structure tradeoffs so decisions are calmer and safer.

## Disclaimer
This tool provides structured thinking, not professional advice.
